# SQL Agent V7: semantic grounding and candidate quality

## Scope and frozen roles

V7 preserves V5/V6 artifacts and keeps Qwen V5 as the public default. Seed
`20260907` partitions the exposed V6 development material by question group into
40 reproduction-audit, 60 critic-calibration, and 100 selection cases. The V5
200-case holdout is inspected regression material. The 1,033-case V6 final is
referenced only by manifest identity and is not openable through the V7 data API.

The six-hour ledger records run UUID, executable, command hash, process start,
heartbeat, atomic lease, elapsed model time, and status. Predictions checkpoint
per case. Capture completeness, application status, and quality gates remain
separate. Gold SQL and reference results exist only in scoring callbacks.

## Components

- **Auto schema:** full schema up to 10 KB, otherwise V5 hybrid retrieval with
  foreign-key closure.
- **Value index:** read-only, checksum-addressed whole-column type/null/count
  profiles, bounded categorical examples, normalized storage forms, and numeric
  ranges stored outside Git.
- **Evidence packet:** exact-first question-conditioned matching, at most four
  one-second probes, five values per column, 12 facts, and 4 KB.
- **Typed intent:** Pydantic concepts for grain, projections, measures, filters,
  grouping, HAVING, ordering, limits, distinctness, joins, ratios, dates,
  subqueries, and set operations; one bounded JSON repair.
- **Candidates:** reference-like Arctic direct, Arctic IR-guided, and Qwen
  decomposed. SQLGlot structural signatures remove non-diverse duplicates.
- **Critic and result evidence:** IR-to-AST checks, row/column/null/duplicate/range
  summaries, ordered and unordered hashes, majority-result grouping, and
  `needs_review` on unresolved disagreement.
- **Repair:** one allowlisted SQLGlot subtree edit; unrelated AST changes reject
  the repair. Every query still passes the V3 read-only guard and worker.

Public requests may select `pipeline_profile: v5 | v7_grounded`. V5 is the
default. Public V7 permits at most two candidates and generated evidence only.
Three candidates and `none | oracle | generated` evidence modes are restricted
to evaluation CLI code.

## Advancement rules

The 20-case candidate pilot must reach 0.65 oracle EX before full candidate work.
Full selection would require 0.70 oracle EX, 0.60 selected EX, 0.97 completion,
0.90 high-confidence critic precision, unchanged databases, and p95 at most 20
seconds. The separately approved Arctic Q5 matched diagnostic completed and did
not improve Q4, so no further quantization is authorized. Talon remains gated.
The locked final additionally requires a separate compute approval and frozen
winner.

Measured outcomes and the stop decision are in [V7-RESULTS.md](V7-RESULTS.md).
