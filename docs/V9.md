# SQL Agent V9: execution-grounded semantic reasoning

## Objective

V9 tests whether explicit evidence roles and small, deterministic database probes
help Arctic Q4 use the accurate database facts reconstructed in V8. It is an
exposed-development experiment, not an official BIRD result. Qwen V5 remains the
application default.

The protocol was frozen before inference under
`artifacts/v9/sql-agent/protocol.json`. It reuses the exact V8 20-case pilot and
40 exposed cases, caps model work at 3,600 seconds, charges $0 to APIs, and keeps
the 1,033-case locked final closed.

## Components

### Evidence utilization metric

The scoring-only metric parses reference and predicted SQL with SQLGlot and
labels each evidence item as `correctly_used`, `ignored`, `misapplied`,
`unnecessarily_used`, or `contradicted`. It measures mechanical SQL effects,
not general semantic entailment. Reference SQL and expected results never enter
model prompts.

### Scoped evidence

Each fact declares its permitted SQL role and non-implications:

- literal, encoded, and normalized values may affect predicates;
- storage facts may justify conversion only when the question already requires
  numeric/date work and never imply aggregation or grouping;
- join facts may supply an `ON` predicate only when both tables are required;
- descriptions bind concepts to identifiers but do not request an operation.

Packets retain V8's 4 KB and 12-fact bounds.

### Deterministic probes

V9 can execute at most four one-second probes per question. Implemented shapes
verify value existence, numeric storage/ranges, and join cardinality. Queries are
parameterized or fixed-shape, execute through a read-only SQLite URI with
`query_only`, the existing authorizer, disabled extension loading, and a progress
deadline. The source database hash is checked before and after every probe set.
The model cannot generate exploratory probe SQL.

## Gates

The staged order is cache-v2 control, scoped evidence, then probes. Probes may
run only when scoping reduces regressions without reducing EX or completion.
Verified IR and the exposed 40-case run require at least six recoveries, at most
one regression, five net recoveries, +0.10 EX, 0.95 completion, p95 below 20
seconds, and no database mutation. Failure stops the campaign.

V9 excludes multi-candidate generation, Talon, Q5, external APIs, fine-tuning,
and any locked-final access.
